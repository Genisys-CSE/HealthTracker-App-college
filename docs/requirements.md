# HealthTracker App - MVP Requirements (HA-1)

Prepared by: Yug Chaturvedi (Business Analyst role) | Status: for Product Owner sign-off

## 1. Scope (prioritised, MoSCoW)

| Priority | Requirement | Story |
|---|---|---|
| Must | User can register and sign in securely | HA-3 |
| Must | User can log daily steps, weight, sleep and vitals | HA-4 |
| Must | Data is stored reliably and synced across devices | HA-5, HA-6 |
| Must | App is tested end to end and released to the App Store | HA-7, HA-8, HA-9 |
| Should | Weekly trend charts | HA-14 |
| Could | Daily reminders to log data | HA-15 |
| Won't (this release) | Wearable device sync | HA-16 |

## 2. Non-functional requirements

- **Privacy:** health data is encrypted in transit and access requires authentication.
- **Offline use:** entries can be logged offline and synced when the connection returns.
- **Performance:** the dashboard loads in under 3 seconds on a mid-range phone.

## 3. Assumptions and constraints

- Team velocity is 20 story points per 2-week sprint.
- Target release date: 16 November 2026 (v1.0).
